# NexaCart

A premium full-stack e-commerce portfolio project built for the CodeAlpha Full Stack internship.

## Run locally

1. Install packages: `npm run install:all`
2. In one terminal, run `npm run dev`
3. In a second terminal, run `npm run server`

The frontend opens through Vite; the API runs at `http://localhost:5000`.

## Roadmap

- Authentication with JWT
- MongoDB models for users, products and orders
- Cart persistence and checkout page
- Admin dashboard for product and order management
